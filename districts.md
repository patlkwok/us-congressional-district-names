# The 435 Districts

Names for every U.S. congressional district under the geographic naming convention, using boundaries in effect for the 2026 elections.

The rules that produced these names, and the reasoning behind them, are in the [README](README.md). Machine-readable form: [districts.csv](districts.csv).

Each state section notes which map it uses. Several are contested — Texas, Louisiana, Tennessee and Missouri were all in live litigation as of August 2026.

To propose a change, open an issue using the district correction template.
